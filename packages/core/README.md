# @trajectonomics/design-system

Pure data for the Trajectonomics design system: Primitive Tokens, Semantic Tokens, the Semantic Token Contract and the built-in `light` and `dark` Themes. No dependencies.

```bash
bun add @trajectonomics/design-system
```

Pair it with [`@trajectonomics/design-system-theme`](https://www.npmjs.com/package/@trajectonomics/design-system-theme) to turn a Theme into CSS, or with [`@trajectonomics/design-system-svelte`](https://www.npmjs.com/package/@trajectonomics/design-system-svelte) for components.

Source, issues and the glossary: <https://github.com/trajectonomics/design-system>. MIT licensed.
