# @trajectonomics/design-system-theme

Pure behaviour for the Trajectonomics design system: `defineTheme` with Contract validation, Theme CSS emission, the prebuilt `light` and `dark` Theme CSS, and the Tailwind Theme Stylesheet.

```bash
bun add @trajectonomics/design-system-theme @trajectonomics/design-system
```

`@trajectonomics/design-system` is a peer dependency. The package exports `./themes/light.css`, `./themes/dark.css` and `./tailwind.css`.

Source, issues and the glossary: <https://github.com/trajectonomics/design-system>. MIT licensed.
